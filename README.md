# FRET-and-Morphology-at-FA-and-AJ
MATLAB pipeline for quantifying molecular tension and structural morphology at focal adhesions (FAs) and adherens junctions (AJs), using phasor-based FLIM-FRET tension sensors. The pipeline was developed to compare tension at vinculin-based FAs and VE-cadherin-based AJs in different conditions of cell monolayers. 

Requirements: DIPImage
